# Highways 26 - Japanese Carnival Edition

Premium frontend website for the Highways 26 technical symposium featuring a vibrant **Japanese Carnival (Matsuri)** theme.

## ✨ Live Demo
[https://highways.vercel.app](https://highways.vercel.app)

## Features
- Immersive Matsuri-themed design
- Responsive & mobile-first
- Event schedules and details
- Registration flows
- Smooth animations and interactions

## Tech Stack
- React 18 + TypeScript
- Tailwind CSS / Modern CSS
- Vercel Deployment

## 🚀 Quick Start

```bash
git clone https://github.com/BalaKrishnan1708/highways.git
cd highways
npm install
npm run dev
```
